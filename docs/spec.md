# グッズ購入計算ツール 仕様（v1）

グッズを買うときに「今カゴに入れているグッズが何円分か」「あと何円使えるか」をスマホで一目で確認でき、過去の購入履歴も見返せるツール。

## 前提

- 使う人：自分ひとり
- 端末：まずはスマホ（ブラウザ）。ホーム画面に追加してアプリのように使う
- 予算の単位：**イベントごと**
- 集計：イベント単位に加えて、**月ごと・年ごと**の合計も見られる

## 画面構成

画面は下の3つ。画面下部のタブで切り替える。

### 1. イベント一覧（ホーム）

- 「＋ 新しいイベント」ボタン
- イベントのカード一覧（新しい順）
  - イベント名、日付、予算、使った金額、状態（買い物中 / 購入済み）
- カードをタップすると「買い物画面」へ

イベント作成時の入力項目：

| 項目 | 必須 | 例 |
|---|---|---|
| イベント名 | ○ | ○○ライブ 物販 |
| 日付 | ○ | 2026-11-03（初期値は今日） |
| 予算 | ○ | 15,000 |
| メモ | | 会場受け取り |

### 2. 買い物画面（メイン）

画面上部に常に表示する**サマリー**（スクロールしても固定）：

- **合計金額**（大きく表示）
- **予算**
- **残り**（予算 − 合計）。マイナスになったら赤字で「◯円オーバー」と表示
- 予算に対する使用率のバー

合計の内訳：

```
合計 = グッズ小計 + 送料 + 手数料
```

グッズの入力（1行ずつ追加）：

| 項目 | 必須 | 備考 |
|---|---|---|
| グッズ名 | ○ | |
| 単価 | ○ | 円、整数 |
| 個数 | ○ | 初期値 1。＋／－ボタンで増減 |
| 「買う」チェック | | 初期値オン。オフにすると合計から外れる（迷っている物用） |

- 各行に小計（単価 × 個数）を表示
- 行は削除できる

**まとめて入力**（テキスト・画像から）：

- グッズ一覧のテキストを貼り付けると、各行からグッズ名と単価を読み取って候補を出す
  - 「名前 1,500円」「名前 ¥1,500」「名前 1500」の1行形式と、名前の次の行に金額だけがある形式に対応
  - 「合計」「送料」などの行は候補に出すがチェックを外しておく
- スクショなどの画像を選ぶと、文字を読み取って同じように候補を出す
  - 無料のOCR（Tesseract.js）をブラウザ内で動かす。画像は外部に送らない
  - 初回だけライブラリと日本語データ（数MB）をダウンロードする
  - 元の画像と白黒にした画像（暗い背景は反転）の両方を読み、同じ位置の商品は名前・金額それぞれ自信の高い方を使う
  - 自信の低い行（写真部分などのゴミ）は捨てる
  - 商品名は画面上の位置で決める：金額と同じ行の左側、なければ金額のすぐ上で横位置が重なる行。横並びの商品も混ざらない
  - スマホ上端の時刻や「1会計1点まで」などの注意書きは商品名にしない
  - OCR が ¥ を「\」「半」と読む、(税込) が崩れる、といったよくある読み間違いは自動で直す
- iPhone では写真アプリの「テキスト認識表示」でコピーして貼り付ける方が正確なので、画面で案内する
- 候補は追加前に名前・金額を直したり、チェックで外したりできる。追加時の個数は 1

送料・手数料（グッズとは別の欄）：

| 項目 | 備考 |
|---|---|
| 送料 | 円、初期値 0 |
| 手数料 | 円、初期値 0（決済手数料・システム利用料など） |

ボタン：

- **購入確定**：イベントを「購入済み」にして履歴に入れる。確定後も編集は可能
- イベントの編集・削除

### 3. 履歴・集計

- 切り替えタブ：**イベント / 月 / 年**
- イベント：購入済みイベントの一覧（日付・名前・合計・予算との差）
- 月：月ごとの合計金額と件数。タップするとその月のイベント一覧
- 年：年ごとの合計金額と件数。タップするとその年の月別内訳
- 集計に入るのは「購入済み」のイベントの、「買う」にチェックが入ったグッズ ＋ 送料 ＋ 手数料
- 集計の基準日はイベントの日付

## データ

- スマホのブラウザ内（localStorage）に保存。サーバーやログインは不要
- ブラウザのデータを消すと消えるため、**バックアップ書き出し / 読み込み（JSONファイル）** を設定画面に用意する

```
Event {
  id, name, date (YYYY-MM-DD), budget, shipping, fee, memo,
  status: "shopping" | "purchased",
  items: [{ id, name, price, qty, checked }],
  createdAt, updatedAt
}
```

## 作り方

- HTML / CSS / JavaScript だけの静的なWebページ（ビルド不要）
- GitHub Pages で公開し、スマホからURLを開いてホーム画面に追加
- オフラインでも開けるようにする（PWA）

## 進め方

1. この仕様を決める
2. スマホで使える最初の版（イベント一覧 + 買い物画面 + 送料・手数料）
3. 履歴・集計画面（イベント / 月 / 年）とバックアップ
4. 実際に使って直す ← いまここ
