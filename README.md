# Calc-Buy-Goods

グッズを買うときに、選んでいるグッズの合計と予算の残りを一目で確認できるスマホ向けツール。

仕様は [docs/spec.md](docs/spec.md) を参照。

## 使い方

1. GitHub Pages で公開したURLをスマホのブラウザで開く
2. 共有メニューから「ホーム画面に追加」すると、アプリのように使える
3. 「＋ 新しいイベント」で予算を決めて、グッズを追加していく

データはスマホのブラウザの中だけに保存される。

## 手元で動かす

ビルドは不要。リポジトリのフォルダでWebサーバーを立てて開く。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```
